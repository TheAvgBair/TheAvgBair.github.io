# Portfolio hub

The live GitHub Pages site is built from main at the repository root. Preserve all app support/privacy routes. Custom CI runs only on the existing repository-specific self-hosted labels; GitHub-managed Pages deployment is allowed.

The root Seen on Instagram section reads instagram/reels.json. The social repository owns that generated feed and immutable thumbnails under instagram/. Only complete, verified live motion Reel receipts may enter the feed. Future queued videos must not appear as posted. The bio URL and #instagram anchor stay stable.

Card links point directly to the verified tool, template, product or exact App Store listing. Card-specific consented outbound click counts identify the selected card, not the Reel that caused a visit or a downstream conversion. Keep measurement off until consent and preserve untracked navigation if storage or analytics is unavailable.

Before release run node --check site.js, node .github/scripts/validate-stashpin.mjs, and git diff --check; verify desktop/mobile rendering plus one actual destination navigation. Stage only intended files. Site publication requires the authorized release path and a live check, not just a local commit.
